## Overview

Div Color Change is a minimal static web page. It contains a button labeled "Change Color" and an empty `div` (class `mydiv`), styled with `style.css` and wired up through `script.js`. The project name indicates that it demonstrates changing the color of that `div`.

## Features

- A **Change Color** button
- A `div` element (`.mydiv`) that acts as the color target
- Separate HTML, CSS, and JavaScript files
- Responsive viewport meta tag
- No build step or dependencies

## Getting Started

### Prerequisites

- A modern web browser
- Git (optional, only if you want to clone the repository)

### Installation

```bash
git clone https://github.com/adelmhmd77/div-color-change.git
cd div-color-change
```

No package installation or build step is required.

### Usage

Open `index.html` in your browser, or visit the [live demo](https://adelmhmd77.github.io/div-color-change/), then click the **Change Color** button.
